# 出力の絶対ルール

- 出力はこの節だけ。1行目は必ず `## 6. 予定と振り返り` で始める。`## 1.`〜`## 5.` の節は書き直さない。
- 前置き・説明・確認・挨拶・結びの言葉は一切書かない。コードブロック(```)で囲まない。
- 日本語で書く。アプリ名・ファイル名・リポジトリ名・店名・サイト名は原文のまま書く。
- 下に書かれていないことを推測で足さない。

# 入力データの読み方

- 「作業日報」は、PCの画面記録から書いた対象日の日報です。PCで何を何時にしていたかは、こちらを正とします。
- 「モーニングページ」は、本人が朝に話した内容を整理したものです。
  - 「対象日の予定」は対象日の朝に話した、その日にやるつもりだったことです。
  - 「翌朝の振り返り」は翌日の朝に、対象日を思い出して話したことです。食事・外出・買い物・運動・睡眠など、PCの外のことはこちらにしか出てきません。
  - 音声を文字にしたものなので、人名・店名・金額・時刻に誤りがあります。「※不確か」と書かれたことは断定せず、「（不確か）」と添えます。
- 作業日報とモーニングページで時刻や内容が食い違うときは、PCの作業は作業日報を、PCの外のことはモーニングページを採ります。
- 入力が無い項目（予定または振り返りが「（なし）」）は、その入力を使う小見出しを省きます。

# 出力形式

## 6. 予定と振り返り

### 予定と実績

- 「対象日の予定」の項目ごとに1行の箇条書きで、実際にどうだったかを書く（例: 「メルマガの続きを読む → 夜に読んだ」「電子工作の学習 → 手を付けていない」）。
- 実績は、作業日報とモーニングページの振り返りの両方から判断する。どちらにも出てこなければ「→ 記録なし」とする。
- 予定に無かったが大きく時間を使ったことがあれば、最後に「予定外: …」として1行で書く。

### PCの外の活動

- 「翌朝の振り返り」から、食事・外出・買い物・運動・人との連絡・睡眠など、PCの外の活動を **3〜8個** の箇条書きで、時間帯が分かれば「（12時半頃）」のように添えて書く。
- 作業日報に既に書かれているPCの作業は繰り返さない。

### 気になったこと・持ち越し

- **1〜5個** の箇条書き。振り返りや「気になること・考えたこと」に出てきた気がかり・考えたこと、予定のうち終わらず翌日以降に回ったことを書く。
